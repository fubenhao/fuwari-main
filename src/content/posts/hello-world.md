# 你好，我是付本豪

欢迎来到我的工作博客。我是 **付本豪**，一名 Java 开发工程师，现就职于一家智能仓储物流科技公司。

开这个博客，是想把我在智能仓储与自动化物流领域的工作沉淀、技术思考和项目复盘记录下来，也希望能和同路人交流。

## 我在做什么

公司主营家具板材行业的智能仓储与自动化物流整体解决方案——立体库、四向车、堆垛机、RGV、桁架机器人、输送线等。作为软件侧核心成员，我深度参与并主导了多个项目「方案 → 设计 → 开发 → 交付」的全过程。

入职初期以 Java 后端开发为主，随项目推进逐步承担 WMS/WCS 软件方案设计、系统设计、数据库设计、接口集成、现场调试与上线培训，目前已形成一体化独立作战能力，可独立承接一个仓储软件项目的完整生命周期。

## 我的技术栈

- **后端**：Java / Spring Boot / MyBatis-Plus / Shiro（Guns 框架）
- **业务**：WMS（仓储管理）/ WCS（仓储控制）/ MES 集成
- **设计**：数据库建模、储位规划、路线规划、软件方案与业务蓝图
- **算法**：遗传算法库位匹配、货位距离排序（曼哈顿距离）、装车排柜
- **集成**：与 MES 及多家异构系统完成接口对接

## 我做过的事

- **某大型家居企业工业 4.0 智能工厂立库项目**（2023—2024）：主导 WMS/WCS 系统设计，打通「来料组托 → 入库 → 越库 → 排车装车 → 出库」全链路。
- **某家居企业板材自动拣选 WMS 项目**（2025—2026）：基于 Guns 框架独立开发 WMS（690+ Java 文件），从需求到上线独立闭环。
- **某板式家具企业板材库自动拣选项目**（2025—2026）：负责线边仓接口、桁架机器人及设备层通信对接等复杂集成。

## 未来想做什么

1. **产品化沉淀**：把项目经验抽象成标准化的 WMS/WCS 产品平台与配置化引擎。
2. **算法深化**：库位匹配、装车排柜、RGV 调度等核心算法工程化、参数化。
3. **架构升级**：推动系统微服务化与统一接口平台建设。
4. **团队与影响**：从独立交付向带团队 / 技术方案评审转变，沉淀团队规范与知识库。
